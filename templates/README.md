# テンプレートディレクトリ

このディレクトリには、プロジェクト開発で使用するテンプレートファイルが格納されています。

## 📋 利用可能なテンプレート

### PLAY_FEEDBACK_TEMPLATE.md
プレイテストフィードバック用テンプレート

### PLAYTEST_PROMPT.md
AI向けプレイテスト実行用プロンプト集

#### 目的（PLAY_FEEDBACK_TEMPLATE.md共通）
- 実際のツール使用体験から具体的な改善点を抽出
- 開発優先度の決定
- ユーザビリティ問題の体系的な記録

#### 使用方法

**人間による手動プレイテストの場合**:
```bash
# 1. テンプレートをコピー
cp templates/PLAY_FEEDBACK_TEMPLATE.md docs/feedback/PLAY_FEEDBACK_[日付].md

# 2. 実際のゲームブックプレイをシミュレート
./gamebook new "火吹き山の魔法使い"  # 具体的な冒険を開始
# 体力、技量、運、アイテムなどを管理しながら進行

# 3. テンプレートに従ってフィードバックを記録
# 4. 開発チームと共有
```

**AIによるプレイテストの場合**:
```bash
# 1. PLAYTEST_PROMPT.mdから適切なプロンプトを選択
# 2. AIに送信してプレイテストを実行依頼
# 3. AIが自動的にFEEDBACK_TEMPLATE.mdに従ってフィードバック作成
# 4. 必ずdocs/feedback/PLAY_FEEDBACK_YYYY-MM-DD.md として保存される
```

**重要**: プロンプトには明確にファイル保存先が指定されているため、AIは自動的に適切な場所にファイルを作成します。

#### 記述のポイント
- **具体性**: 実際のコマンドとエラーを記載
- **再現性**: 他の人が同じ問題を再現できる情報
- **優先度**: ⭐で5段階評価（⭐⭐⭐⭐⭐が最高優先）
- **実用性**: 改善案は実装可能で効果的か

#### 重要度評価基準
- **⭐⭐⭐⭐⭐**: ツール使用を断念するレベルの致命的問題
- **⭐⭐⭐⭐**: 大幅にユーザビリティを損なう重要問題  
- **⭐⭐⭐**: 改善により体験が向上する問題
- **⭐⭐**: あると便利な改善
- **⭐**: 将来的な検討事項

## 🤖 AI向けの使用指示

### プレイテストフィードバック作成時
1. **自然なプレイ体験の再現**: 単なる機能テストではなく、実際のゲームブックプレイの流れを忠実にシミュレート
2. **具体的な冒険ストーリーの作成**: 抽象的な操作確認ではなく、具体的な冒険物語を通じて検証
3. **想定外の発見を重視**: 開発者が予期しない使用パターンや問題を積極的に探求
4. **多様な視点での評価**: 初心者・経験者・異なるプレイスタイルの視点を含める
5. **感情移入した評価**: プレイヤーの感情（興奮、困惑、苛立ち、満足感）を意識した評価

### ゲームブックプレイシミュレーションの重要要素
- **ゲームシート管理**: 体力、技量、運、アイテム、所持金などの数値管理
- **条件分岐の実体験**: 「もし○○を持っていれば」系の判定を実際に行う
- **戦闘・運試し**: サイコロ判定やランダム要素を含む分岐
- **複数プレイ**: 異なる選択による別ルートの探索
- **失敗・再開**: 行き止まりや死亡からの復活と再挑戦

### フィードバック品質のチェックポイント
- [ ] 具体的な冒険ストーリーが含まれているか
- [ ] 実際のゲームブックプレイの流れが再現されているか
- [ ] 想定外の使用パターンが探求されているか
- [ ] プレイヤーの感情や体験が記述されているか
- [ ] 改善の優先度が実際の使用場面で評価されているか

## 📁 ファイル管理

### 命名規則
- プレイテストフィードバック: `PLAY_FEEDBACK_YYYY-MM-DD.md`
- バージョン別フィードバック: `PLAY_FEEDBACK_v0.2.0.md`

### 保存場所
- **バージョン別フィードバック**: `docs/feedback/PLAY_FEEDBACK_v[バージョン].md`
- **日付別フィードバック**: `docs/feedback/PLAY_FEEDBACK_YYYY-MM-DD.md`
- **検証者別フィードバック**: `docs/feedback/PLAY_FEEDBACK_v[バージョン]_[検証者名].md`

### Git管理
- フィードバックファイルはすべてGit管理対象
- 各フィードバックは専用ブランチで作成してPR経由でマージ推奨

## 🔄 更新・改善

### テンプレートの改善
- フィードバックの記述品質向上のため、テンプレート自体も継続的に改善
- 新しい評価項目や記述パターンがあれば追加検討

### 使用状況の追跡
- テンプレート使用時の問題や改善点があれば、GitHubのIssueで報告
- より効果的なフィードバック収集のため、テンプレート形式を進化
