# Entities Layer 仕様書

## 概要
純粋なビジネスロジックとドメインモデルの仕様

## エンティティ

### Gamebook（ゲームブック）
- **タイトル**: ゲームブックの名前
- **パラグラフ一覧**: パラグラフ番号をキーとしたマップ
- **現在位置**: 現在のパラグラフ番号
- **移動履歴**: NavigationStepの配列による移動履歴

### Paragraph（パラグラフ）
- **番号**: パラグラフ番号（主キー）
- **概要**: パラグラフの説明文
- **選択肢一覧**: このパラグラフから選択可能な選択肢
- **訪問回数**: このパラグラフを訪れた回数

### Choice（選択肢）
- **説明文**: 選択肢の内容
- **遷移先**: 選択時の移動先パラグラフ番号
- **選択状態**: 選択済み/未選択

### Session（セッション）
- **開始時刻**: プレイセッションの開始時刻
- **履歴**: 訪問したパラグラフの順序

### NavigationStep（移動履歴）
- **From**: 移動元パラグラフ番号
- **To**: 移動先パラグラフ番号

## ビジネスルール

### パラグラフ管理
- パラグラフ番号は重複不可
- パラグラフ番号は1以上の整数
- 一度作成されたパラグラフの番号は変更不可

### 選択肢管理
- 同一パラグラフ内で同じ説明文の選択肢は作成不可
- 選択肢の遷移先は存在しないパラグラフでも設定可能（後から作成される前提）
- 選択状態は選択済みに変更後、未選択に戻すことも可能

### 移動ルール
- 現在位置から選択可能な選択肢のみ選択できる
- 直接移動（moveコマンド）も可能（デバッグ・巻き戻し用途）

### 移動履歴管理
- 全ての移動をNavigationStepで記録
- 移動元→移動先の単純な記録
- 移動実装詳細への依存禁止（純粋性確保）
- 履歴の追加は可能、削除・変更は不可（不変性確保）

## データ整合性

### 不変条件
- パラグラフ番号の一意性
- 選択肢の説明文の一意性（同一パラグラフ内）
- 訪問回数は0以上

### 状態遷移
- 未訪問 → 訪問済み（訪問回数が0から1以上に）
- 未選択 → 選択済み（選択肢の状態変更）
