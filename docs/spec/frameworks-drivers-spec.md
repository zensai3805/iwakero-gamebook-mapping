# Frameworks & Drivers Layer 仕様書

## 概要
フレームワーク統合、UI実装、外部ツールとの連携仕様

## CLI Framework

### cobra
コマンドラインインターフェースフレームワーク

#### コマンド構造
```
gamebook
├── new <title>              # 新規作成
├── add <number> <desc>      # パラグラフ追加
├── choice <number> <desc> <target>  # 選択肢追加
├── select <para> <choice>   # 選択実行
├── move <number>            # 直接移動
├── show                     # 状態表示
├── list                     # 一覧表示
└── switch <title>           # 切り替え
```

## 表示システム

### ツリー表示
パラグラフ階層構造の表示

#### 経路ハイライト機能
- **連続経路**: 選択肢で繋がっている経路を強調表示
- **非連続経路**: 経路が途切れている場合、辿れる範囲のみ表示
- **複数経路**: 実際に辿った経路のみハイライト

#### 表示制御
- NavigationStep履歴を活用した正確な経路判定
- 選択済み選択肢の視覚的区別（[✓]マーク）
- 未選択選択肢の表示（[ ]マーク）
- 現在地の特別ハイライト
- 経路が途切れている場合の表示制御

#### 表示例
```
連続経路の場合:
└─┬1: start
  └─┬[✓] B → 12
    └─┬12: test1
      └─┬[✓] D → 11
        └──11: (未定義) ## 現在地としてハイライト

非連続経路の場合（moveで11に直接移動後の表示）:
└─┬1: start
  ├─┬[ ] A → 11
  │ └──11: (未定義) ## 現在地のみハイライト
  └─┬[✓] B → 12
    └─┬12: test1
      └──[ ] D → 11 ## 経路表示なし
```
