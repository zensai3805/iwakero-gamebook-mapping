# 移動履歴管理機能仕様書

## 概要
Issue #107のバグ修正に伴い実装される移動履歴管理機能の統合仕様書です。  
ゲームブックの複雑な経路構造において、正確な現在地表示と経路追跡を実現します。

## 問題の背景
現在のツリー表示では、複数の経路から同じパラグラフに到達する場合、現在地のハイライトが間違った経路で表示される問題があります。

### 再現例
```
パラグラフ1 → 選択肢A → パラグラフ11
パラグラフ1 → 選択肢B → パラグラフ12 → 選択肢D → パラグラフ11
```

上記の状況で選択肢Bを選んでパラグラフ12に移動し、さらに選択肢Dを選んでパラグラフ11に移動した場合、現在地が選択肢Aのルートで表示されてしまいます。

## 解決方針

### 基本設計原則
1. **単純性**: 移動履歴は単純な移動記録のみ
2. **表示制御**: 経路表示制御は表示レイヤーで実装
3. **純粋性**: Entitiesレイヤーでの実装詳細非依存
4. **責務分離**: 各レイヤーの役割明確化

### 移動の考え方
- **全ての移動**: 移動元→移動先の単純な記録
- **表示制御**: 経路が途切れている場合、辿れる範囲のみ表示

## 機能仕様

### 移動履歴記録
- 全ての移動をNavigationStepエンティティで記録
- 移動元→移動先の単純な記録
- 履歴の不変性確保（追加のみ、削除・変更禁止）

### 経路表示
- ツリー表示で現在のプレイ経路を正確にハイライト
- 経路が途切れている場合、辿れる範囲のみ表示
- 複数経路がある場合の適切な表示制御

### NavigationStepエンティティ
- **From**: 移動元パラグラフ番号
- **To**: 移動先パラグラフ番号

## 技術アーキテクチャ

### Entities Layer
- NavigationStepエンティティの定義
- 単純な移動履歴管理機能
- 移動実装詳細への依存禁止

### Usecase Layer
- 移動履歴記録ロジック
- 全ての移動に対する統一的な履歴記録

### Interface Adapters Layer
- 移動履歴管理インターフェース定義
- Repository/Presenterの拡張

### Frameworks & Drivers Layer
- 経路連続性を考慮したフローデータ変換
- 経路に基づく現在地ハイライト
- 経路が途切れている場合の表示制御
