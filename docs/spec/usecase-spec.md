# Usecase Layer 仕様書

## 概要
アプリケーションのユースケースとビジネスワークフローの仕様

## 主要ユースケース

### ゲームブック管理

#### 新規ゲームブック作成
- タイトルを指定してゲームブックを作成
- デフォルトでパラグラフ1を作成
- 作成したゲームブックを現在のゲームとして設定

#### ゲームブック切り替え
- 既存のゲームブックに切り替え
- 現在位置を保持したまま切り替え

#### ゲームブック一覧表示
- 作成済みのゲームブック一覧を表示
- 各ゲームブックの進捗状況を表示

### パラグラフ管理

#### パラグラフ追加
- 番号と概要を指定してパラグラフを追加
- 重複チェックを実施
- 追加後、自動的にそのパラグラフに移動

#### パラグラフ情報更新
- 既存パラグラフの概要を更新
- 選択肢の追加・削除・更新

### 選択肢管理

#### 選択肢追加
- 現在のパラグラフに選択肢を追加
- 説明文と遷移先を指定
- 重複チェックを実施

#### 選択肢選択
- 利用可能な選択肢から選択
- 選択状態を「選択済み」に更新
- 遷移先パラグラフに移動
- 移動履歴に記録
- 未定義パラグラフへの遷移時は警告表示

### ナビゲーション

#### 直接移動
- パラグラフ番号を指定して直接移動
- デバッグや巻き戻し用途
- 移動履歴に記録

#### 履歴表示
- これまでの移動履歴を表示
- セッション単位での履歴管理

### 移動履歴管理

#### 移動履歴記録
- 全ての移動をNavigationStepエンティティで記録
- 移動元→移動先の単純な記録
- 移動方法に関わらず統一的な履歴記録

#### 経路判定
- 複数経路から同じパラグラフに到達する場合の正確な経路特定
- 現在セッションでの移動履歴を活用
- 表示レイヤーでの適切な経路ハイライト支援

### 可視化

#### フロー図生成
- パラグラフ間の遷移関係を表示
- 選択済み/未選択の視覚的区別
- 訪問済み/未訪問の表示

#### マップ生成
- 2Dグリッド形式でパラグラフを配置
- ヒートマップによる訪問頻度表示

#### 統計情報表示
- 総パラグラフ数
- 訪問済みパラグラフ数
- 選択済み選択肢数
- 完了率

## ワークフロー

### 基本的なプレイフロー
1. ゲームブック選択/作成
2. 現在のパラグラフ確認
3. 選択肢から選択または新規パラグラフ追加
4. 選択により次のパラグラフへ移動
5. 2-4を繰り返し

### データ入力フロー
1. パラグラフ番号入力（現在位置がデフォルト）
2. パラグラフ概要入力
3. 選択肢追加（複数可）
4. 各選択肢の遷移先設定

### 移動履歴記録フロー
1. NavigationStep作成（移動元→移動先）
2. 移動履歴に追加
3. 経路表示情報更新

## エラーハンドリング

### 入力検証
- パラグラフ番号の重複
- 選択肢の重複
- 無効な番号（0以下）

### 警告
- 未定義パラグラフへの遷移
- 未保存の変更がある状態での終了
