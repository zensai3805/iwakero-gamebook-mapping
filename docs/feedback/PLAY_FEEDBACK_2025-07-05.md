## 🔥 致命的な不便さ

### 未定義パラグラフによるフロー図汚染問題 ⭐⭐⭐⭐⭐ (最高優先)

**問題**: 未定義パラグラフへの選択肢がフロー図に表示され続け、表示が著しく汚染される

**実際の体験**:
```bash
# 未定義パラグラフへの選択肢を複数追加
./gamebook choice 1 "すぐに山へ向かう" 10
./gamebook choice 5 "普通の剣で挑戦" 20  
./gamebook choice 5 "魔法のお守り" 25
./gamebook choice 15 "裏口を探す" 35
./gamebook choice 30 "戦闘勝利" 40
./gamebook choice 30 "戦闘敗北" 45

./gamebook show
# → 未定義パラグラフ10,20,25,35,40,45への選択肢が全て表示
# → フロー図が存在しないパラグラフで汚染される
# → 統計情報も不正確（存在しない選択肢も含む）
```

**具体的な破綻状況**:
- **フロー図の汚染**: 存在しないパラグラフへの選択肢が大量表示
- **重複表示**: 同じ選択肢が重複して表示される
- **統計の不正確さ**: "選択肢 3/15"で未定義への選択肢も計上
- **視認性の悪化**: 実際の構造把握が困難
- **選択肢の無限増殖**: 未定義パラグラフへの選択肢が増え続ける

**影響**: 
- **表示の完全な破綻**: 実用的なフロー図として機能しなくなる
- **誤解を招く表示**: 存在しないパラグラフが存在するかのように見える
- **操作性の悪化**: 目的の情報を見つけるのが困難
- **大規模化での破綻**: 未定義パラグラフが増えるほど表示が悪化

**改善案（実用性重視）**: 
```bash
# CLIコマンド対応
./gamebook show                   # デフォルト: 接続されている未定義のみ表示
./gamebook show --hide-undefined  # 未定義パラグラフへの選択肢を完全非表示
./gamebook show --all-undefined   # 全ての未定義パラグラフを表示（管理用）
./gamebook pending list           # 未定義パラグラフ一覧
./gamebook pending connected      # 現在地から接続されている未定義のみ
./gamebook pending orphaned       # 接続されていない孤立未定義パラグラフ

# 表示レベルの段階的設定
./gamebook show --undefined-scope connected    # 接続されているもののみ（推奨）
./gamebook show --undefined-scope reachable    # 現在地から到達可能なもの
./gamebook show --undefined-scope all          # 全て（管理者向け）

# インタラクティブモード対応（実用性重視）
./gamebook  # インタラクティブモード起動時
# → デフォルト: 現在地から接続されている未定義のみ表示
# → 統計情報: 「未定義(接続): 3パラグラフ」
# → [F1]キーで表示範囲切り替え: 接続のみ → 全て → 非表示

# 現在地からの接続重視表示
🗺️ 可視化マップ & フロー図: [未定義: 接続のみ]
└─┬1: 冒険の始まり
  ├─── [✓] 酒場で情報収集 → 5
  ├─── [ ] すぐに山へ向かう → 10 [未定義・接続]
  └─┬5: 酒場での情報収集
    ├─── [✓] 銀の剣を購入 → 15
    ├─── [ ] 普通の剣で挑戦 → 20 [未定義・接続]
    └─── [ ] 魔法のお守り → 25 [未定義・接続]
    
# 孤立未定義パラグラフ（40, 45など）は表示されない

# 実用的な統計情報
=== ゲーム名 ===
📊 パラグラフ 5/5 | 選択肢 3/9 | 未定義(接続) 3 | 探索率: 100%
#   ↑実在のみ    ↑実在のみ   ↑接続されているもののみ
#   [詳細: 未定義(孤立) 3] ← 必要時のみ表示

# 管理機能での全表示
[メニュー選択: 未定義パラグラフ管理]
接続されている未定義: 10, 20, 25 ← 優先表示
孤立している未定義: 40, 45     ← 折りたたみ可能
# → 接続されているものを優先的に作成支援
```

**実用性の観点**:
- **通常プレイ**: 現在地から接続されている未定義のみで十分
- **全体管理**: 全ての未定義パラグラフが必要（孤立したものの清理など）
- **表示負荷**: 接続されているもののみなら表示負荷が大幅軽減

**推奨表示ポリシー**:
1. **デフォルト**: 接続されている未定義のみ表示
2. **管理モード**: 全ての未定義パラグラフ表示
3. **クリーンモード**: 未定義パラグラフ完全非表示

**優先度再評価理由**:
実際の使用で、未定義パラグラフへの選択肢がフロー図を深刻に汚染し、実用性を著しく損なうことが判明。表示品質の根本的な問題として最高優先に変更。

### 直接移動パラグラフの可視化問題 ⭐⭐⭐⭐

**問題**: moveコマンドで直接移動したパラグラフがフロー図に表示されない

**実際の体験**:
```bash
./gamebook add 100 "魔法使いの隠れ家"
./gamebook move 100
./gamebook show
# → パラグラフ100がフロー図に表示されない
```

**影響**: 
- 探索したパラグラフが可視化されない
- 全体構造の把握が困難
- 「その他のパラグラフ」にも表示されない

**改善案**: 
- 直接移動したパラグラフも可視化対象に含める
- 「未接続パラグラフ」として別セクションで表示
- 手動で遷移関係を設定する機能

### フロー図のスケーラビリティ問題 ⭐⭐⭐⭐⭐

**問題**: 現在の線形フロー図は大規模ゲームブックで破綻する

**実際の想定される問題**:
```bash
# 100パラグラフのゲームブックの場合
./gamebook show
# → 画面に収まらない巨大な縦スクロール
# → 末端の選択肢を確認するために大量スクロール必要
# → 全体構造の把握が不可能
# → ターミナルの表示限界を超える
```

**スケール想定**:
- **小規模** (5-20パラグラフ): 現在の表示で問題なし
- **中規模** (50-100パラグラフ): 画面スクロールが必要、視認性低下
- **大規模** (200-400パラグラフ): 実用性が完全に失われる
- **超大規模** (500+パラグラフ): ターミナル表示が不可能

**具体的な破綻シナリオ**:
```bash
# ファイティングファンタジー級のゲームブック (400パラグラフ)
└─┬1: 冒険の始まり
  ├─── [✓] 北の道 → 15
  ├─── [ ] 南の道 → 45  
  ├─── [ ] 東の道 → 78
  └─┬15: 暗い森
    ├─── [✓] 左の道 → 32
    ├─── [ ] 右の道 → 67
    └─┬32: 小川のほとり
      ├─── [✓] 橋を渡る → 89
      ├─── [ ] 泳いで渡る → 156
      └─┬89: 廃墟の村
        ├─── [ ] 教会を調べる → 201
        ├─── [ ] 酒場を調べる → 234
        ├─── [ ] 井戸を調べる → 267
        └─┬201: 古い教会
          ├─── [ ] 地下室に降りる → 298
          ├─── [ ] 祭壇を調べる → 312
          └─┬298: 地下室の秘密
            ├─── [ ] 本を読む → 345
            ├─── [ ] 箱を開ける → 378
            └─── [ ] 階段を降りる → 389
              (この調子で400パラグラフ継続...)
# → 画面を遥かに超える表示、実用性ゼロ
```

**影響**: 
- **視認性の完全な破綻**: 全体構造の把握が不可能
- **ナビゲーション困難**: 目的のパラグラフまでのスクロールが膨大
- **メモリ使用量の増大**: 巨大なツリー表示でのパフォーマンス低下
- **実用性の喪失**: 大規模ゲームブックで使用不可能

**改善案**: 
```bash
# 階層表示とフィルタリング
./gamebook show --depth 3  # 3階層まで表示
./gamebook show --from 100 --depth 2  # パラグラフ100から2階層
./gamebook show --visited-only  # 訪問済みのみ表示
./gamebook show --current-branch  # 現在の分岐のみ表示

# ページネーション

# セクション分割表示
./gamebook show --section "洞窟エリア"  # エリア別表示
./gamebook show --range 100-150  # 範囲指定表示

# インタラクティブ探索
./gamebook explore  # 矢印キーでノード間移動
# → j/k でパラグラフ移動
# → h/l で階層移動
# → Enter で詳細表示

# 概要表示
./gamebook show --summary
# → 主要ルートのみ表示
# → 分岐点の数の統計
# → 探索率の視覚化
```

```bash
# パラグラフ番号入力時の理想的な表示
```

```bash
# → 特殊状態: なし

# → ✅ 運9 ≥ 8 : 条件を満たします
./gamebook sheet check item "銀の剣"
# → ✅ 銀の剣を所持しています

# 戦闘支援
./gamebook sheet combat
# → 技量11 + サイコロ2個 = 技量値入力
# → 敵技量値: [入力]
# → 自動戦闘計算と体力減算
```

- **ゲームブックの本質**: 数値管理はゲームブックの核心機能

### 入力回数の多さと操作負荷 ⭐⭐⭐⭐

**問題**: 単一のパラグラフ記録に多数のコマンド実行が必要

**実際の体験**:
```bash
# パラグラフ1つと選択肢2つを記録するために必要なコマンド数
./gamebook add 1 "冒険の始まり。体力24、技量11、運10。金貨20枚を持って火吹き山へ向かう。村の酒場で情報収集をするかそのまま山へ向かうか選択を迫られる。"
./gamebook choice 1 "酒場で情報収集をする" 5
./gamebook choice 1 "すぐに山へ向かう" 10
./gamebook select 1 1
./gamebook add 5 "酒場での情報収集。バーテンダーから火吹き山の魔法使いについて聞く。魔法使いは恐ろしい存在で、多くの冒険者が戻ってこなかった。ただし、銀の剣があれば勝算があるという情報を得る。体力+1（温かい食事）。"
# → 合計5コマンド + 長文入力複数回
```

**影響**: 
- **入力疲労の蓄積**: 1時間のプレイで数十回のコマンド実行
- **中断によるフロー阻害**: コマンド入力のたびにプレイが中断
- **入力ミスのリスク**: 長いコマンドでのタイプミス頻発
- **記録作業への集中**: ゲーム内容より操作に意識が向く

**改善案**: 
```bash
# 理想的なワンショット記録

  --choice "酒場で情報収集をする:5" \
  --choice "すぐに山へ向かう:10" \
  --select 1

# または対話式一括入力
./gamebook batch-add
# → パラグラフ番号: 1
# → 説明: [長文入力]
# → 選択肢1: 酒場で情報収集をする → 5
# → 選択肢2: すぐに山へ向かう → 10
```

## 結論

### 全体評価

現在のツールは、ゲームブックの記録と可視化において非常に高い完成度を誇っています。特にフロー図の視認性と選択状況の表示は、期待を大幅に上回る品質です。インタラクティブモードのUIも美しく、継続的な使用に適しています。

### 主要課題

最も深刻な問題は「段落順序依存問題」です。実際のゲームブックプレイでは、選択肢を先に記録してから移動先を読むという自然な流れが存在しますが、現在のツールではこの流れが阻害されます。この問題は、ツールの実用性を大幅に損なう可能性があります。

### 最重要改善点

v0.2.3では、段落順序依存問題の解決と**入力支援機能の実装**を必須とします。特にTab補完と候補表示は、現代的なツールとして不可欠な機能です。これらの改善により、入力効率が劇的に向上し、認知負荷が大幅に軽減されます。

### 将来性

基本的な記録・可視化機能が既に高品質で実装されているため、今後の改善により、真に実用的なゲームブック支援ツールとして完成する可能性が高いです。特に条件分岐の高度化と数値管理機能が実装されれば、手作業では困難な複雑なゲームブック攻略が可能になります。

#### 自然なプレイフロー阻害問題
実際のゲームブックプレイでは、以下の流れが自然です：
1. 現在のパラグラフを読む
2. 選択肢を確認し、記録する
3. 選択肢を選ぶ
4. 移動先のパラグラフを読む
5. 移動先の内容を記録する

現在のツールでは、ステップ2と4の間で移動先パラグラフが未定義だと警告が出て、自然な流れが中断されます。

#### 想定外の発見
- パラグラフ番号を飛ばした追加（例：1→5→15→100）が可能
- 存在しない選択肢番号の適切なエラーハンドリング
- インタラクティブモードの美しいUI表示
- 直接移動パラグラフの可視化問題

- フロー図の階層表示と選択状況の可視化
- 統計情報（探索率等）の表示
- 自動読み込み機能
- 警告メッセージの適切さ
